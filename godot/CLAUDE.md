# 무협 가로판 (Godot) — 작업 지침

세로 화면에서 **가로로 나아가는** 방치형. 주인공은 오른쪽으로 달리고, 적은 오른쪽에서 오고, 싸움은 멈추지 않는다.
엔진은 **Godot 4.6**(GDScript, 2D, Compatibility 렌더러). 사용자 확정 2026-11-13 "고도로 옮기자" — 목표가 스토어 출시라서다.
옛 판(저장소 루트 `src/`, 세로 탑뷰 HTML)과 `side/`(가로판 HTML 원본, v0.1.1 에서 멈춤)는 건드리지 않는다. 그림(`../assets/`)과 수치만 빌려 온다.

한국어로 대화하고 주석도 한국어로 쓴다.

## 지킬 것

1. **코어 화면이 보기 좋아질 때까지 다른 걸 안 넣는다.** 시스템은 하나씩, 사용자가 고른 순서로 되살린다. 옛 판은 15개를 쌓았다가 첫 30분에 쓸 수 있는 게 둘뿐이었다.
2. **숫자는 `data.gd` 에만.**
3. **밸런스 곡선(`DIFF_*`·`GROW`·`EXP_*`·`SILVER_*`·`TRAIN`)은 옛 판 확정값이다.** 체감 속도를 고치려고 건드리지 않는다 — 박자는 `WAVE_*`·`HERO_SPD` 로 맞추고 `test.gd` 출력으로 판단한다.
4. **게임 로직(`game.gd`)은 그리기를 모른다.** 노드·그림·입력을 넣지 않는다 — 머리 없는 검사가 이것만 돌린다.
5. **그림은 `../assets/` 가 원본이다.** `art/` 는 복사본이라 손으로 고치지 않는다. 새 키는 `data.gd` 의 `asset_keys()` 에 들어가야 실린다(→ `sync_art` → `--import`).
   새 그림이 필요하면 제미나이 프롬프트를 사용자에게 적어 준다. 이펙트·UI 도형은 코드로 그려도 된다.
6. **바꾸면 웹으로 내보내 크로뮴으로 찍어 사용자에게 보인다**(`tools/shot.js`). 머리 없는 실행은 화면을 못 본다.
7. **GDScript 는 타입 추론이 엄격하다** — 사전·배열에서 꺼낸 값으로 `:=` 를 쓰면 파스 오류다. `var x: float = d["k"]` 처럼 타입을 적는다.

## 명령 (전부 `godot/` 에서)

```bash
python3 tools/godot.py --headless --script res://test.gd          # 구동 검사 + 진행 박자 (SIM_MIN=분, 기본 30) — 10초 안쪽
python3 tools/godot.py --headless --script res://tools/sync_art.gd  # ../assets → art/ (asset_keys 기준, 없는 키는 실패)
python3 tools/godot.py --headless --import                          # 새 그림·글꼴을 고도가 읽게 (.import 생성)
python3 tools/export_web.py                                          # 웹 내보내기 → dist/ (아티팩트용으로 엔진을 조각냄)
(cd dist && python3 -m http.server 8770 &) ; NODE_PATH=../node_modules node tools/shot.js   # 기기 5종 실기 → ../review/godot/
NODE_PATH=../node_modules node tools/shot.js skills 14 350      # 시험 차림(#demo=skills|pick|boss|arts|info)으로 폰 화면을 14장 이어 찍는다
TAP=72,676 NODE_PATH=../node_modules node tools/shot.js pick 1  # 찍기 전에 그 자리를 눌러 본다 (카드가 눌리는지)
```
시험 차림은 `main.gd` 의 `_demo()` — 웹은 주소 끝 `#demo=이름`, 그 밖엔 환경 변수 `WUXIA_DEMO`. 저장을 안 건드린다. **새 화면 상태를 만들면 차림을 하나 더한다**(이펙트는 그 순간을 찍어야 보인다).

`tools/godot.py` 가 엔진(72MB)과 웹 내보내기 틀(9MB)을 `~/.cache/godot-wuxia` 에 받아 놓는다. 컨테이너가 새로 뜨면 처음 한 번 다시 받는다.
**게시**: `dist/index.html` + 나머지 9개 파일을 아티팩트 `files` 로. 아티팩트는 파일당 15MB·정해진 확장자만 받아서
`export_web.py` 가 엔진(38MB)을 `w0~w2.wasm` 으로 나누고 게임 묶음(`.pck`)을 `pack.wasm` 이라는 이름으로 싣는다(페이지의 fetch 가로채기가 다시 잇는다).
안드로이드 빌드는 이 환경에서 못 한다(구글 SDK 다운로드 막힘) → GitHub Actions 로 돌린다(아직 안 만듦).

## 구조

```
project.godot   창 440×822(논리), stretch=canvas_items·expand — 가로 440 이상·세로 822 이상이 늘 보인다
data.gd         설계 숫자 전부 + asset_keys()
game.gd         상태·수식·step(dt)·저장 (그리기 없음)
art.gd          그림·글꼴 창고
back.gd         원경 (하늘 + 흐르는 그림, 이 층만 선형 필터)
scene.gd        장면 그리기. **같은 스크립트를 세 층으로 얹는다**(layer): 0 세계(안개·땅·인물) · 1 빛(가산 합성 — 타격·초식 이펙트) · 2 글자(피해 숫자·초식 이름)
main.gd         화면 짜기(HUD·스킬창·패널·깨달음 카드를 코드로 만든다)·배치(_layout)·루프·멈칫(hitstop)
main.tscn       뿌리 노드 하나 (나머지는 main.gd 가 만든다)
test.gd         머리 없는 검사
fonts/          IBM Plex Sans KR(본문)·Noto Serif KR(제목) — KS X 1001 한글 2350자 + 영숫자만 추린 것 (OFL)
tools/          godot.py · export_web.py · sync_art.gd · shot.js
```

## 화면

- 가로 440 논리 단위 기둥. 위 = **장면**, 아래 = **패널**. 넓은 화면에선 기둥이 가운데 서고, 높은 화면에선 장면이 먼저 커지고(572 까지) 나머지는 패널이 받는다.
- **패널이 먼저 제 높이(`PANEL_H`)를 갖는다.** 패널에 줄을 더하면 `PANEL_H` 와 project.godot 의 창 높이(= `SCENE_MIN + PANEL_H`)를 같이 올리고 `shot.js` 로 낮은 화면을 확인한다.
- 장면 순서: 하늘 → 원경(천천히 흐름) → 밤 안개(원경만 덮는다) → 중경 대나무 실루엣 → 땅·자갈 → 인물 → 연출 → 위쪽 어둠.
- 톤 레퍼런스: Soda Legend — 어두운 남색 안개, 캡슐 HUD, 가는 선, 강조색 하나(강철 파랑), 보스만 장밋빛.
- 적 그림은 전부 오른쪽 보기라 **항상 뒤집어** 그린다. 맞은 순간 번쩍임은 modulate 를 1 넘게(곱).
- 글자는 값이 바뀔 때만 다시 그려진다(Label). 카드는 Button 위에 자식을 얹은 것 — 자식은 전부 `MOUSE_FILTER_IGNORE`.
- 맨 위 여백 `_sat()`: 웹에서 iframe 이면 40(아티팩트 앱 바), 폰은 안전 영역.
- **패널 맨 아래는 탭 바**(v0.4 사용자 "스킬창이나 스탯창 등을 이동할 수 있는 버튼 UI가 없네"): 수련 · 무공 · 정보.
  탭 내용은 셋 다 같은 높이(`TAB_H`)라 바꿔도 화면이 안 움직인다. 새 탭은 `_tab_box` 로 만들고 `_ui()` 의 보이기 줄과 탭 바 목록에 더한다.
  **탭을 저절로 바꾸지 않는다** — 누르려던 자리에 딴 카드가 끼어들면 잘못 고른다(깨달음도 금빛 점으로만 알린다).
  무공 표의 칸을 누르면 맨 아래 한 줄에 그 무공의 설명이 뜬다. 칸은 처음에 한 번만 만들고 글자·색만 바꾼다.

## 싸움의 박자

세계는 x 한 줄. **한 떼를 잡고 → 달려서 → 다음 떼를 만난다.** 남은 적이 `WAVE_LEFT` 이하면 다음 떼를 화면 밖 오른쪽에 미리 세운다.
주인공은 닿는 적을 한 번에 다 친다. 쓰러지면 3초 운기조식 뒤 제자리에서 다시 — 잃는 건 시간뿐.
10단계를 채우면 수호자. 지면 10단계로 물러나고, 이기면 지금은 10단계에서 계속 사냥한다(다음 구역 없음).

## 무공 — 계속 싸우면서 고른다 (v0.3)

사용자 "단판성이 좋을까 계속 싸우게 하는 게 좋을까" → **지속 전투를 유지하고, 단판 게임의 '석 장 중 하나 고르기'만 가져왔다.**
방치·오프라인 정산·누적 성장이 지속 전투에 묶여 있어서다. 단판으로 바꾸려면 이 결정부터 다시 한다.

- **깨달음**: 경지가 오를 때마다 1번(`insight`). 석 장(`offer`)을 내밀고 하나를 고른다 — 새 초식 / 연마(+30%) / 심법(스탯 %).
  안 배운 초식이 있으면 한 장은 꼭 그것이다(need = 경지). **깨달음은 무공 탭 안에서 고른다**(탭에 금빛 점 + 맨 아래 안내 한 줄) — 싸움은 위에서 계속된다.
- **초식 5**(선풍퇴·파공권·암향지·활인기공·붕산장)는 쿨이 차면 알아서 쓴다. **한 번에 하나**(`CAST_GAP`). **심법 3**(공격·체력·회복)은 곱.
- 스킬창은 장면의 땅 띠 위(쿨이 시계 방향으로 걷힌다). 시전하면 이름을 외친다(세리프, 초식 색).
- **새 초식을 넣으면**: `data.gd ARTS` 한 줄(strip·hand·col) → `game.gd _art_fire` 에 효과 → `scene.gd _glow` 에 이펙트 → `test.gd` 무공 항목 → `_demo()` 로 찍어 확인.

## 이펙트

- 빛은 전부 **가산 합성 층**(scene.gd layer 1, `CanvasItemMaterial.BLEND_MODE_ADD`)에 그린다 — 겹칠수록 밝아져 도트 위에 네온처럼 뜬다. 색은 초식의 `col` 하나가 정한다.
- 타격점 번쩍임+방사선(`hit`) · 불꽃(`spark`) · 참격 호(`slash`) · 초식별(회오리 고리·권기 탄과 꼬리·빛줄기·빛기둥·땅 충격) · 시전 중 손끝 기운.
- **멈칫**(`hitstop`): 초식이 맞는 순간 main 이 step 을 잠깐 쉰다. game.gd 는 값만 세운다 — 검사·박자와 무관.
- **날아가는 적**: 쓰러지면 뒤로 튀고(평타는 살짝, 초식은 멀리 — 포물선·회전), 땅에 닿으면 먼지.
- 흩날리는 댓잎은 `CPUParticles2D` 하나(`LEAF_*`).

## 지금 있는 것 / 없는 것

있다: 죽림(근접 9종 + 대나무 마왕) · 경지(자동) · 수련 3종 · 무공 8종(깨달음으로 고른다) · 이펙트 · 저장(`user://side1.json`).
없다(되살릴 후보, 순서는 사용자와 정한다): 다음 구역 4곳 · 장비 · 원거리/비행 몹 · 오프라인 정산 · 소리 · 안드로이드 빌드.
고도라서 새로 쓸 수 있는 것(아직 안 씀): 2D 조명 · 셰이더 · 진짜 물리 엔진(지금 날아가는 적은 손으로 푼 포물선이다).

박자 실측(v0.3, 깨달음은 첫 장·수련은 싼 것부터): 5분 죽림 6 · 10분 죽림 9 · 15분 수호자 격파 — 옛 판(5분 죽림 6~7)과 비슷해졌다.
알려진 거친 곳: 적이 주인공 앞 한 점에 겹쳐 선다 · 30분에 한 번도 안 쓰러진다(너무 쉽다) · 첫 로딩이 무겁다(엔진 38MB) · 탭 아이콘이 마름모 하나뿐이다(그림 없음).
