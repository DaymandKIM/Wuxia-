# 가로판 v0.4 — 아래 탭 바 (수련 · 무공 · 정보)

사용자 "아래 스킬창이나 스탯창 등을 이동할 수 있는 버튼 UI가 없네". 수련 화면 하나뿐이라 배운 무공도 스탯도 볼 데가 없었다.

- **탭 바**를 패널 맨 아래에: 수련 · 무공 · 정보. 탭 내용은 같은 높이라 바꿔도 화면이 안 움직인다.
- **무공 탭**: 8종을 한 표로 — 익힌 것(단계)·아직 안 익힌 것·경지가 모자란 것(어둡게, "일류 1성부터"). 칸을 누르면 맨 아래 한 줄에 설명과 수치.
- **정보 탭**: 경지·다음 경지·공격·체력·회복·무공 수·처치·쓰러짐·수호자·판.
- **깨달음은 무공 탭 안에서 고른다** — v0.3 은 수련 카드를 가려 버렸다. 이제 탭에 금빛 점과 안내 한 줄로만 알린다(탭을 저절로 바꾸지 않는다).
- 전투 수치 줄·판번은 정보 탭으로 옮겼다.

## 가로판 v0.3 — 무공을 배운다 · 이펙트

사용자 "스킬이나 이런 거 배우게 해보자. 단판성이 좋을까 아니면 이렇게 계속 싸우게 하는 게 좋을까. 이펙트도 넣어봐".

- **지속 전투는 그대로, 고르는 재미만 가져왔다.** 경지가 오를 때마다 **깨달음** — 석 장 중 하나(새 초식·연마·심법). 고르는 동안에도 싸움은 계속된다.
- **초식 5**(선풍퇴·파공권·암향지·활인기공·붕산장, 자동 시전·한 번에 하나) + **심법 3**(공격·체력·회복). 시전 동작·메달 그림은 옛 `assets/` 그대로.
- **스킬창**: 장면 땅 띠 위, 쿨이 시계 방향으로 걷힌다. 시전하면 초식 이름을 외친다.
- **이펙트**: 가산 합성 층(타격 번쩍임·방사선·불꽃·참격 호·초식별 연출·손끝 기운) · 멈칫 · 쓰러진 적이 날아간다 · 흩날리는 댓잎.
- 박자: 5분 죽림 6 · 15분 수호자 격파(v0.2 는 5분 5 · 20분). 검사에 무공 10항목 추가.

## 가로판 v0.2 — Godot 로 옮김

사용자 "고도로 옮기자"(목표가 스토어 출시). HTML 가로판 v0.1.1(`side/`, 550줄)을 Godot 4.6 으로 그대로 옮겼다 — 게임 내용은 같다.

- 로직(`game.gd`)·숫자(`data.gd`)는 줄 단위 이식. 박자 실측이 HTML 판과 같다(5분 죽림 5 · 20분 수호자 격파).
- 화면은 `_draw` 한 장(scene.gd) + 코드로 만든 Control UI(main.gd). 그림 177장은 `../assets` 에서 복사, 글꼴은 한글 2350자만 추려 넣었다(2.8MB).
- 웹 내보내기가 아티팩트에서 열린다 — 엔진(38MB)을 13MB 조각으로 나눠 싣고 페이지에서 잇는다(`tools/export_web.py`). 사용자 확인 "열림".
- 검사: `test.gd`(머리 없이 로직 14항목 + 박자) · `tools/shot.js`(크로뮴으로 기기 5종).
