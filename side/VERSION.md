# 가로판 v0.1 — 코어 한 화면

옛 판(세로 탑뷰 사방 전투, src/ 9,500줄·시스템 15개)이 너무 무거워져 **가로 진행 판을 새 폴더에서 작게 다시 시작**했다.
사용자 확정: "횡스크롤 진행, 화면은 세로" · "지금처럼 끊김 없는 지속 전투". 톤 레퍼런스는 Soda Legend(어두운 남색 안개·캡슐 HUD·가는 선).

- 달린다 → 떼를 만난다 → 싸운다 → 지나간다 → 10단계 뒤 수호자(대나무 마왕). 죽림 한 구역.
- 성장은 둘뿐: **경지**(처치 수련치, 자동) · **수련**(공격·체력·회복, 은자).
- 밸런스 곡선(DIFF·GROW·REALM·SILVER·TRAIN)은 옛 판 값을 그대로 옮겼다. 그림도 전부 옛 `assets/` 재사용 — 새 그림 0장.
- 화면: 위 절반 장면(캔버스) + 아래 절반 패널(HTML). 탭·팝업·상점 없음.
