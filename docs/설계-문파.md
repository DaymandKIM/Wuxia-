# 문파 — 설계 계획 (2026-09-16, 사용자 "문파 슬슬 만들어봐 계획 말해보고")

## 전제 (이미 확정된 것)
- 주인공은 장무기형 — **어느 문파에도 가입하지 않는다.** 8계보(청죽문·소림·무당·화산·아미·개방·당문·마교)의
  무공은 "인연이 닿으면 배운다"(무공 탭 그대로).
- 그래서 여기서 말하는 문파 = **내 문파 경영**: 주인공이 **이름 없는 문파를 세워 천하에 이름을 알린다**
  (화산귀환식 문파 재건 서사 — 조사에서 가장 반응 좋은 축). **이름은 플레이어가 짓는다**, 기본 **무명문 無名門**(사용자 확정 2026-09-16
  "추천으로 가자, 기본은 무명문" — 명성 단계 '무명'과 맞물려 "무명문이 천하제일이 됐다"). 청죽문은 8계보 중 하나로 남는다(무공 계보).
- 규칙: 일일 숙제 없음 · 프레스티지 없음 · 광고 없음 · 코어는 자동 전투 구경. 문파는 **은자 sink + 방치 수익**이지
  새 조작 루프가 아니다. 후반 은자 잔고가 쌓이기 시작하니(sim) 그걸 먹는 것이 첫 목적.
- 문파 수익은 전투 수익의 **20% 수준**, **깊이(현 단계 처치 은자)에 비례**(고정값은 후반에 무의미 — idle-game-balance).

## 구조 — 세 층
### 1. 전각 殿閣 (은자 sink, 영구 % 효과) — v2.91
청죽문 터에 전각 5채. 레벨업은 은자, 비용 base×1.32^Lv, 상한은 명성 단계로 열린다.

| 전각 | 효과 | 결 |
|---|---|---|
| 연무장 演武場 | 공격력·공격 속도 +% | 수련의 다른 축 (수련은 레벨당 +2%, 전각은 느리고 큼) |
| 장경각 藏經閣 | 무공 숙련 획득 +%, 연마 비용 −% | 무공 축 |
| 약방 藥房 | 체력·회복 +%, 쓰러짐 회복 시간 −% | 생존 |
| 객당 客堂 | 제자 자리 +N, 문파 수익 +% | 제자 축 (2층) |
| 산문 山門 | 은자 획득 +%, 명성 획득 +% | 경제 |

### 2. 제자 弟子 (방치 수익 + 계보 보너스) — v2.92
- **합류 = 인연**: 구역 보스 첫 격파(구역당 1명 확정), 기연 카드에 '입문 청'(은거기인과 별개), 명성 문턱마다 1명.
  뽑기·모집권 같은 재화는 안 만든다.
- 제자마다 **계보(8문파 중 하나)** + **자질(하·중·상·천)**. 이름은 신조(작명 규칙 준수).
- **문파 수익**: 제자 합계 × 현 단계 처치 은자 × 계수. 온라인엔 초당 누적, 오프라인 정산에 그대로 얹는다
  (오프라인 상한 8시간 동일). 전투 수익 대비 20%가 목표.
- **계보 보너스**: 제자의 계보 문파 무공 효과 +%(자질별). "소림 제자가 있으니 소림 무공이 는다" — 무공 탭 타일에 표시.
- 제자 성장은 없다(관리 부담 금지). 자질이 곧 값. 후반엔 같은 계보 3명 → 상위 자질 1명 합성(장비와 같은 결) 정도만.

### 3. 명성 名聲 (진행 게이지, 상한 해제) — v2.91
- 처치·보스·업적 받기로 쌓인다(인연 karma와 별개, 게이지는 보여 준다 — 기연과 달리 놀라움이 목적이 아님).
- 단계: 무명 → 향리 → 일방 → 명문 → 천하제일. 단계마다 전각 상한·제자 자리·(3층) 파견 슬롯이 열린다.

### (선택) 4. 파견 派遣 / 협행 — v2.93, 사용자 판단
- 제자 몇을 N시간 보내 은자·수련치·장비를 받아 온다. 돌아올 이유는 되지만 **일일 숙제에 가깝다** — 넣는다면
  벌칙 없이(안 보내도 손해 없음, 자동 재파견 토글). 기본은 **보류**.

## 문파 본진 비무 (사용자 아이디어 2026-09-16 — "소림사·무당파 본진에 가서 싸워 뭔가 얻고, 그곳 출신 제자가 내게 온다")
- **사냥터 여정 지도에 문파 본진 7곳**(소림사·무당산·화산·아미산·개방 분타·당가보·마교 총단)을 별도 줄로. 구역 진행과
  별개로 **명성 단계**로 열린다(무명 → 향리에 첫 문파). 본진 = **비무 3판**(제자 파도 2 + 장로/수좌 보스 1), 사거리·AI는
  기존 틀(수호무사 정예 + 탄 보스).
- **첫 승리 보상**: 그 문파 출신 **제자 합류**(계보 확정, 자질은 명성 단계 따라) + 명성 큰 폭 + 그 문파 무공 **계보 보너스 해금**
  ("소림에서 인정받았다 — 소림 무공 +%"). 무공 습득 조건(경지+은자)은 건드리지 않는다 — 비무는 보너스이지 관문이 아니다.
- **재도전**: 언제든. 은자·명성 소량 + 낮은 확률로 그 문파 제자 한 명 더(자리 있을 때). 일일 제한 없음.
- 제자 합류 경로는 이걸로 정리: **비무 첫 승리(주) + 기연 '입문 청'(부) + 명성 문턱(보조)**. 구역 보스 1명 확정은 뺀다.
- **필요한 시트(사용자)**: 문파마다 제자 1종(4×4 걷기·공격·피격·죽음, 강도 규격) + 장로 1종(보스 규격). 7문파 = 14장이라
  **소림부터 1문파 파일럿**으로 시작해 틀을 굳힌 뒤 늘린다. 프롬프트는 docs/프롬프트-몬스터.md에 "문파 제자·장로" 절로.
- 순서 갱신: v2.91 전각+명성+탭 → v2.92 제자·수익(기연 입문 청으로 먼저 합류 가능) → v2.93 소림 비무 파일럿(시트 오면) → 나머지 6문파.
