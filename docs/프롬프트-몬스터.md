# 몬스터 시트 프롬프트 — 완성형 (한 블록 = 한 몬스터, 그대로 복사)

공통 규칙이 이미 합쳐져 있다. 블록 하나를 통째로 제미나이에 붙이면 된다.
시트가 나오면 자르지 말고 채팅에 그대로 붙여넣기 — 원본 복원해서 추출한다.
낭인은 v2.9로 이미 게임에 들어갔다. 추천 순서: 위에서 아래로.

## 폐촌 · 들개 (근접)

```
2D pixel art monster sprite sheet, 16-bit retro JRPG style, side view, facing RIGHT in every frame, same character size and same ground level in every cell. Each frame inside a thin dark-bordered cell of equal size, no empty cells. Solid magenta background (#FF00FF). No text, no labels, no watermark. Crisp 1px black outlines, limited palette. Rows: row1 = idle 4 frames (breathing), row2 = walk 4 frames, row3 = attack 4 frames (windup, strike, follow-through, recover), row4 = hit reaction 1 frame + death 2 frames (collapsing, fallen). The monster: a mangy feral dog with ribs showing, patchy dark grey-brown fur, foaming jaws, low aggressive posture. Walk row = low prowling run, attack row = lunging bite. Dusty grey-brown palette.
```
