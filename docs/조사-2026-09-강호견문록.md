# 강호견문록 — 무협 조사 종합 (2026-09-03)

세 갈래 병렬 조사(김용 원전·장르 심리·시장 정세)를 한 권으로 묶은 것.
보기 좋은 판은 아티팩트로 게시했고, 이 파일은 저장소용 원문 요약이다.
설계에 이미 반영된 결론은 CLAUDE.md 설계 방침에 있다.

## 卷一 — 김용 15부와 장무기 (주인공의 원형)

- 14부 첫 글자 대련: 비설련천사백록, 소서신협의벽원 (+단편 월녀검)
- 사조삼부곡(사조영웅전→신조협려→의천도룡기): 전대 유산(의천검·도룡도 속 비급)이
  다음 세대의 기연이 되는 구조
- 장무기 공식 = **고난 축적 → 기연 폭발**. 한독(시한부) → 구양신공(저주가 그릇이 됨)
  → 건곤대나이 → 원치 않은 교주 자리 → 끝내 권력을 버림.
  기연은 무작위가 아니라 **고난·선행의 대가** — 그래서 사이다로 읽힌다
- 성격: 선량함이 능력이자 결함. 정·사를 안 가림. 우유부단(비판 지점)
- 주인공 유형: 곽정(노력)·양과(반항)·장무기(기연)·영호충(자유)·위소보(반영웅)
- **게임 반영**: 곽정(방치=반복 수련) + 장무기(기연=이벤트 도약) 합성이 성장 곡선.
  기연은 누적 플레이의 정산으로만. 무공 접미사=기능 매핑(심법/진경=내공,
  권·장·각=공격, 신공=필살)

## 卷二 — 왜 열광하는가 / 무엇에 지치는가

매력 7: ①수치화된 성장(내공·경지 — 서구 팬 유입 1번 이유) ②기연 ③사이다
④협의 낭만(언더독·은원) ⑤강호 관계망(문파·비무) ⑥무공 명칭의 멋
⑦은거고수 판타지(허름한데 강하다)

피로 4: 회빙환 범람 / 먼치킨 원패턴·파워 인플레·용두사미 / 한자 진입장벽 /
초반 노잼. 바라는 것: 낮은 문턱+정통다움 양립(화산귀환 공식), 강호를 사는 느낌,
캐릭터와 관계, 뼈대는 지키고 표면만 비틀기.

수용 차이: 한국(회빙환+웹툰 전성기·노맨스 주류) / 중국(김용 표준, 무협은 선협에
밀림) / 서구(cultivation의 낯선 수치 성장에 열광). 우리의 "쌓이기만 하는 경지"는
세 문화권 공통 코어와 일치.

## 卷三 — 시장 정세

인기작: 화산귀환(회귀+문파 재건+말맛, 후반 원패턴 비판), 나노마신(퓨전+작화),
광마회귀(클리셰 비틀기), 검술명가 막내아들(파워 인플레로 후반 급락),
북검전기(잘 만든 정통의 희소성). 트렌드: 회빙환 기본값, 퓨전 확대.

무협 방치형 게임 유저 불만 순위:
1. **"방치형인데 방치를 못 한다"** (숙제·수동 클릭)
2. 과금 유도 3. 중국산 번역투 4. 광고 강요·인색한 오프라인 보상

칭찬받는 것(천마 키우기): 무과금 가능, 무공 습득·환골탈태급 굵직한 성장 이벤트.
팬 갈증: 경지·무공이 눈에 보이는 게임. 도트 무협은 검증된 포맷.

→ 우리 방침(숙제·광고 없음, 확실한 오프라인 정산)이 불만 목록의 정확한 역상 —
지키는 것 자체가 무기.

  생사현관 돌파 연출) ④강호 만들기(구역·보스 은원 한 줄 → 협행 → 문파) ⑤말맛
