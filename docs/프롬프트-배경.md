# 상단 원경 배경 시트 프롬프트 — 완성형 (한 블록 = 한 구역, 그대로 복사)

세로 화면 **위쪽 30~35%**에 깔리는 구역별 원경(먼 산·탑·안개·구름)이다. 카메라보다
느리게 스크롤(패럴럭스)해서 깊이감·장소감을 준다. 전투는 화면 중하단이라 가독성을
안 해친다. 바닥 텍스처는 넣지 않는다(스프라이트·이펙트와 경쟁 → 어수선).

렌더는 `drawBackdrop`(50-render) — `BACKDROP`(00-data)의 key 이미지를 높이
`VH×h`로 맞춰 가로로 타일링, `ox×par`만큼 느리게 흐르고, 아래 `fade`px는 땅색으로
녹여 지평선을 잇는다. 이미지가 없으면 아무것도 안 그린다(지금 상태).

시트가 나오면 자르지 말고 **채팅에 그대로 붙여넣기**(저장 안 되면 jsonl에서 복원).
추출은 `python bg_extract.py <zone>` — 밝은 마젠타(하늘)만 투명으로 걷는다.
**원경에 보라·자주 안개를 쓰면 마젠타로 오인될 수 있으니** 프롬프트에 "no purple/
magenta tones in the artwork"를 넣어 뒀다.

## 공통 규칙 (프롬프트에 이미 합쳐져 있음)

- 가로로 넓은 한 장(예: 2048×640 비율). **좌우 끝이 이어지게**(seamless tiling)
- 빈 하늘 영역은 마젠타 `#FF00FF` (투명 처리용). 그림엔 보라·자주 계열 금지
- 원경만: 저대비·흐릿한 실루엣, 전경 디테일 없음, 초점 없음 — 앞의 게임이 읽혀야 함
- 아래쪽 가장자리는 땅색과 이어지도록 어둡고 단순하게 마무리(지평선 띠)
- 16-bit 픽셀, 절제된 팔레트, 텍스트·워터마크 없음
