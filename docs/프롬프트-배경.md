# 배경 시트 프롬프트 — 원경(상단) + 바닥(전면) (한 블록 = 한 장, 그대로 복사)

두 층으로 구성한다. 그림은 전부 사용자 제미나이 시트, 코드는 안 그린다.

1. **원경(상단 34%)** — 먼 산·탑·안개·구름. 카메라보다 느리게(패럴럭스). 아래 지평선
   띠는 **그 구역 땅색**으로 끝나서 바닥과 이어진다. 하늘은 마젠타(투명 처리).
   렌더 `drawBackdrop`(50-render) · 데이터 `BACKDROP`(00-data) · 추출 `bg_extract.py`.
2. **바닥(전면 전체)** — 32px 타일이 아니라 **큰 정사각 무봉(4방향 seamless) 텍스처
   한 장**. 저대비·오브젝트 없음(소품은 PROPS로 따로 깔림)·기본색=땅색. 카메라와 1:1로
   흐른다. 마젠타 없음(투명 필요 없음, 꽉 채운 그림). 렌더/추출은 시트 오면 붙인다
   (drawGround 교체·`GROUNDTEX`·`ground_extract.py`).

구역 땅색(ZONES.ground): 죽림 `#6a7a52` · 폐촌 `#6b6350` · 동굴 `#474d54` ·
설산 `#a4b3c0` · 천산 `#7f9a86`.

시트가 나오면 자르지 말고 **채팅에 그대로 붙여넣기**(저장 안 되면 jsonl에서 복원).
**원경·바닥 모두 보라·자주 계열 금지** — 원경은 마젠타로 오인, 바닥은 톤이 튄다.
