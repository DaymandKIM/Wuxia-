# 무공 작명 조사 요약 (2026-09-08)

무공 이름을 "그대로 쓰지 않고 조금 비틀기" 위한 조사. 원문 조사는 80여 개
무공 총람 — 여기엔 게임에 필요한 결론만 남긴다.

## 법적·관행적 경계
- **김용 작품 고유 창작명**(항룡십팔장·독고구검·구음진경·건곤대나이 등)은
  출처가 즉시 특정된다. 김용 측의 실제 소송 사례 있음(팬픽 인명 차용 9년
  소송, 게임 개편권 분쟁). 정식 라이선스 게임만 원명을 쓴다 → **쓰지 않는다**
- **한국 장르 공용 자산**(자하신공·천마신공·매화검법·만천화우·삼재·혼원 등)은
  수십 년 여러 작품이 써서 클리셰화 → 참고·차용 가능
- 소림 칠십이절예 실명(백보신권·나한권 등)도 피한다 → 백보신권을 암향지로 개명

## 작명 문법 (조사 결론)
- 골격: [수식부 1~4자] + [분류 접미사 1~2자], 총 3~6자. 4자가 표준,
  궁극기는 5~6자 (길이 = 격)
- 수식부 재료: 숫자(구=극수·칠=불길·백~만=규모) / 자연물(용·매화·구름·설·산) /
  도가(태극·건곤·무상) / 불가(금강·나한·항마) / 동사(항·타·흡·파·낙) /
  색(자·창·백·혈·금) / 감정·고전 인용(암연소혼·북명)
- 접미사 = 층위: 초식 ~권·장·지·참·퇴 / 심법 ~심법·공·결·경 / 신공 ~신공·대법
- 정파는 神功·眞經(닦는다), 사파는 大法·魔·血·吸(빼앗는다).
  사파에 예쁜 이름을 주면 더 무섭다(만천화우·규화보전)
- 개구리 보스 참고: 합마공(두꺼비 공 — 동물 모방 작명)
- 타구봉법식 하대(下待) 작명의 낙차 유머는 기법이라 재활용 자유

## 우리 게임 적용 (확정)
접미사 문법은 공용으로 채택, 수식부에 **구역 모티프**를 넣어 오리지널화:
죽림 죽·풍·청 / 폐촌 귀·황·곡·야 / 동굴 암·석·유·음 / 설산 설·빙·한·백 /
천산 천·운·성.
