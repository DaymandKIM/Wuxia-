## 시트 프롬프트에 이미 반영한 것 (v2.94.28)

같은 사고를 막으려고 `docs/프롬프트-문파인물.md` 에 넣었다.
- 무기·이펙트를 **칸 안에 여백 두고** 넣고 테두리에 닿지 말 것
- **걷기 줄에도 같은 무기**를 들 것
- 칸에 **강조 테두리를 그리지 말 것**
- 쓰러지는 컷은 **방향을 한쪽으로 통일**할 것
- 배경은 **순마젠타**로(옅은 자주면 도복이 배경으로 지워진다 — 소림 정예 시트)
- 실존 사찰·문파 이름을 넣지 말 것(그림 생성이 거부된다)
- 이펙트 색을 **파랑·청록·흰·초록·금**으로 못 박을 것. 자주·분홍은 배경 판정에 먹힌다 — 당문 장로 침이 그렇게 사라질 뻔했다

## 추출기에 접어 넣을 것 (sr_sheet.py)

지금 여러 에이전트가 같은 스크립트를 쓰고 있어 미뤄 뒀다. **이번 묶음이 끝나면 반영한다.**

**둘 다 v2.95.4 에 반영했다** — `|r-b| < 40` 조건과 `--minblob` 옵션. 아래는 그때의 근거다.

1. **마젠타 걷어내기에 `|r-b| < 40` 조건을 더한다.** 지금 조건(`r>g+10 & b>g+10`)이 **붉은 술·진홍 장포**(r 200·b 60)까지 눌러
   **검은 막대**로 만든다(화산 장로 대기 컷에서 잡혔다). 마젠타 번짐은 r≈b 라 이 조건으로도 그대로 걷힌다.
   **진홍이 들어가는 화산·마교 시트에 특히 필요하다.**
2. **작은 덩어리 버림 문턱 40 → 8 을 옵션으로.** 화산 장로의 **흰 매화 꽃잎**이 8~40px 조각이라 통째로 사라진다
   (그 공격의 정체가 없어진다). 같은 이유로 그 시트는 `--nodeclutter` 가 필요했다.
