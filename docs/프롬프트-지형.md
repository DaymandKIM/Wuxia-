# 지형·배경 소품 시트 프롬프트 — 완성형 (한 블록 = 한 구역, 그대로 복사)

절차 드로잉(v2.57~58.2)은 한계가 있어 우리 파이프라인으로 돌아간다.
블록 하나를 통째로 제미나이에 붙이면 그 구역의 **배경 소품 아틀라스** 한 장이 나온다.
시트가 나오면 자르지 말고 채팅에 그대로 붙여넣기 — 원본 복원해서 추출한다.

이 소품들이 게임에 들어가면 `drawProps`(50-render)가 절차 그림 대신 이 스프라이트를
깐다. 몬스터와 달리 **애니메이션 없음** — 정적 오브젝트다.

## 공통 규칙 (프롬프트에 이미 합쳐져 있음)

- 마젠타 배경 `#FF00FF`, 얇은 다크 테두리 칸, **한 칸에 오브젝트 하나**, 빈 칸 없음
- 각 오브젝트는 칸 안에서 **가로 중앙 · 칸 바닥선에 딱 붙여** 세운다 (땅에 서 있게)
- 칸 위·좌·우로 몇 px 여백을 둬서 **아무것도 잘리지 않게** (윗가지·잎 끝 포함)
- side view(옆에서 본 땅 위 사물), **좌상단 광원**으로 음영 통일 — 게임 스프라이트와 맞춤
- 16-bit 레트로 JRPG 픽셀, 1px 검은 아웃라인, 절제된 팔레트, 텍스트·워터마크 없음
- 얇은 부분(잎·풀)에 마젠타가 배어들지 않게 실루엣을 또렷하게

## 추출 후 반영 (내가 함)

1. 채팅에 붙인 시트를 원본 복원 → 파이썬으로 칸별 덩어리 라벨링 추출
   (마젠타 배경 제거, 바닥 정렬, 공통 규격 캔버스).
2. `assets/`에 구역별 키로 저장 (예: `bamboo_prop0`…, `snow_prop0`…).
3. `blackcheck.py`로 검은 막대·부유 조각 눈검사 → 비전 확인.
4. `PROPS`(00-data)를 스프라이트 목록으로 바꾸고 `drawProps`(50-render)가
   절차 그림 대신 이미지를 그리게 교체. `review.py`로 확대 대조 → 사용자 확인.
5. `fxtest`에 소품 렌더 검사 추가, `spritetest` 통과 확인.
