# 주인공 시트 프롬프트 — 완성형 (그대로 복사해서 제미나이에)

시트가 나오면 **자르지 말고 채팅에 그대로 붙여넣기** — 원본 복원해서 추출한다.
캐릭터가 매번 같아야 하니 아래 "캐릭터 고정 묘사"를 모든 시트에 그대로 넣는다.

## 캐릭터 고정 묘사 (모든 시트 공통 — 이 문장을 프롬프트에 넣는다)

```
The character: a young wuxia hero (Zhang Wuji type), tanned youthful face,
dark brown hair tied in a high ponytail, wearing a cream/off-white
cross-collar martial robe with a blue-grey sash and a slate-blue inner
layer, black cloth shoes, barehanded (no weapon), chibi proportions about
2.5 heads tall.
```

## 이동 · 질주 8프레임 (v2.43 재작업용 — "뛰는 게 아쉽다")

지금 걸 교체할 목적. 핵심은 **걷기가 아니라 질주**다: 앞으로 크게 기울이고,
두 발이 동시에 뜨는 **체공 프레임**이 있고, 머리끈·옷자락이 뒤로 세게 날린다.

```
2D pixel art sprite sheet of a running character, 16-bit retro JRPG style,
side view, facing RIGHT in every frame, same character size and same ground
level in every cell (feet return to the exact same baseline on contact
frames). One single row of 8 equal cells, each frame inside a thin
dark-bordered cell, no empty cells. Solid magenta background (#FF00FF). No
text, no labels, no watermark. Crisp 1px black outlines, limited palette.

The character: a young wuxia hero (Zhang Wuji type), tanned youthful face,
dark brown hair tied in a high ponytail, wearing a cream/off-white
cross-collar martial robe with a blue-grey sash and a slate-blue inner
layer, black cloth shoes, barehanded (no weapon), chibi proportions about
2.5 heads tall.

This is a FAST martial-arts run (light-body qinggong dash), NOT a walk:
strong forward lean, long stride with fully extended legs, arms pumping
hard, ponytail and robe hem streaming back with speed, a sense of momentum.
The 8 frames form one smooth seamless loop: 1 right-foot contact, 2 push
off, 3 airborne suspension (both feet off the ground, body leaning
forward), 4 reach forward, 5 left-foot contact, 6 push off, 7 airborne
suspension, 8 reach forward — then loops back to 1. Keep the head/torso
height steady across the loop so it does not bob wildly; let the legs and
robe do the motion.
```

## (참고) 다른 동작이 필요할 때

- **대기(idle)**: 정면 전투 기수식 1~4프레임(가벼운 숨쉬기). 지금은 이동
  시트 14번 정면 자세를 단일 컷으로 쓴다.
- **경공 착지**: 웅크렸다 일어나는 2~3컷. 지금은 이동 시트 15번 웅크림 단일.
- 정권·시전 동작은 hero_fx 계열 시트에서 이미 추출해 쓴다(권기 katka/katkb 등).

## 무기 공격 시트 재작업 (v2.73.3 — "무기 끝이 다 잘려 있어")

v2.72 무기 시트 5장(검·도·창·봉·부채)은 **칸 안쪽에 얇은 액자선이 있고 무기가 그 선에서 잘린 채** 그려져
있다(review/clipped_cells.png). 잘린 나머지가 액자 밖에 파편으로 떨어져 있어 복구가 안 된다. 다시 뽑을 때는
아래처럼 **액자선·표식 금지 + 무기가 칸 안에 다 들어오게** 못 박는다. 시트가 오면 `python hero_<무기>2.py`
(hero_sheet 공용 추출기)로 그대로 뽑힌다 — 칸 배치는 아래 줄·칸 순서를 지켜야 한다.

공통(무기별 프롬프트 앞에 캐릭터 고정 묘사와 함께 넣는다):

```
Pixel art sprite sheet, 3 rows x 6 cells, each cell 170x170 px, flat solid magenta (#FF00FF)
background everywhere. NO frames, NO borders, NO inner rectangles, NO corner brackets, NO tick
marks, NO labels, NO text — only the character on plain magenta. Each pose must be COMPLETELY
inside its cell with at least 15 px of empty magenta around it: the weapon tip, the swing arc
and any effect must never touch or cross the cell edge (shrink the pose if needed). Side view
facing RIGHT in every cell, feet on the same baseline in every cell, same scale in every cell
(standing height about 130 px). Crisp pixels, no anti-aliasing, dark outline.
```
