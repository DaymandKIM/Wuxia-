# 조사 — TBH: 태스크바 히어로 (2026-09-16, 사용자 "벤치마킹할 만한 게 있나 보자")

출처는 아래 링크(검색 결과 요약 기준 — 원문 페이지는 이 환경에서 막혀 있어 요약·기사 발췌로 정리했다. 수치는 대략).

## 무엇인가
- 뉴젬 스튜디오 + 테서랙트 스튜디오(한국 인디)의 **무료 PC 방치형 RPG**. 2026-05-26 스팀 출시.
- **작업표시줄 위에 띄워 두는 초소형 창**에서 픽셀 용사들이 자동 사냥·파밍. "다른 일을 하는 동안 옆에서 큰다."
- 출시 1주 동접 16만 → 20만 → "50만 코앞"(스팀 3위). 무료 + **스팀 장터 거래**(파밍한 아이템을 진짜 돈으로 사고팖)가 폭발의 핵.

## 시스템 (요약)
- **볼륨**: 3액트 × 4난이도(120스테이지), 몬스터 50+, 아이템 500+(DB 기준 6,000), 스킬·패시브 214, 룬 197.
- **직업 6**: 나이트·레인저·소서러·프리스트·헌터·슬레이어. 파티 편성 — 시작은 **영웅 1칸**, 골드 300 쓰면 '지휘의 룬'으로 2칸, 3칸은 15만 골드.
  "더 많은 영웅 = 더 많은 딜·드랍·경험치" 가 첫 목표.
- **룬 트리**(레벨 3, 100골드로 열림): 전 영웅 공용 영구 노드 197개. 위 **부(富) 갈래**(골드·상자 드랍·가방) / 아래 **성장 갈래**(경험치·전투·영웅 칸).
- **아이템 10등급**: Common → Uncommon → Rare → Legendary → Immortal → Arcana → Beyond → Celestial → Divine → Cosmic.
  등급 = **스탯 큐브 칸 수**(칸마다 접사 하나). "시너지 나는 큐브 2~3개가 랜덤 접사 4개보다 낫다."
- **히어로-드릭 큐브**(제작 허브 8기능): 합성(같은 등급 **9개 → 상위 1개**), 연금, 제작(주·보조무기는 결과 무작위), 장식, 각인(영구 스탯) 등.
- **드랍은 상자**: 일반 상자·보스 상자가 장비·재료의 주 공급원. **오프라인엔 골드·경험치만, 상자는 0** — "오프라인 4배" 류의 편법 글이 돌 만큼 불만.
- **환생/리셋**: 성장이 막히면 리셋 → 보석 같은 재화로 영구 능력치. (가이드 언급. 정확한 규칙은 미확인)
- **QoL**: 아이템 잠금(Alt+클릭)·자동 채우기, 작업표시줄 모드.
- **수익화**: 무료 + DLC(가방 칸 등) + 장터 수수료. "기본 편의(가방)가 DLC" 불만.

## 왜 터졌나 (벤치마킹 후보)
1. **자리 차지 안 하는 방치** — 작업표시줄 한 줄. 우리 = 모바일 세로 한 손, 결은 같다(방치의 마찰을 0으로).
2. **파밍 → 장터 → 진짜 돈**. 우리는 광고·과금·거래 없음(방침). 대신 **파밍의 손맛**(등급 사다리·큐브·합성 9→1)은 참고 가치.
3. **첫 5분 목표가 명확**: "영웅 칸 하나 더" → 골드 300 → 룬. 우리는 첫 5분에 첫 수련 구매·첫 장비 드랍은 있으나 **"다음 목표 한 줄"** 표시가 약하다.
4. **등급 10단계 + 칸 수 = 등급**: 등급이 곧 접사 슬롯이라 등급의 의미가 눈에 보인다. 우리 7등급은 %만 커진다.

## 우리에 가져올 것 / 안 가져올 것
| 후보 | 판단 |
|---|---|
| **"다음 목표" 한 줄**(HUD·복귀 카드에 "다음: 객당 세우기 · 은자 200") | **가져온다** — 방치형은 돌아왔을 때 뭘 누를지 3초 안에 보여야 한다. 작고 효과 큼 |
| **오프라인에도 장비 드랍**(상자 0 불만이 컸다) | **가져온다(보수적)** — 지금 오프라인 드랍 없음(v2.70 "보수적"). 온라인 확률의 절반쯤·최대 N개, 복귀 카드에 아이콘으로 |
| 장비 등급 = 부가 효과 칸 수(접사) | 보류 — 우리 장비는 % 스탯 + 종류별 부가 1개. 등급별 부가 개수 차등(희귀 1·전설 2·초월 3)은 재미있지만 밸런스 재작업 |
| 합성 9→1 (우리 3→1) | 안 가져온다 — 우린 드랍률이 낮아 3→1이 맞다. 대신 상위 등급은 합성 개수를 올리는 건 고려(신화→초월 3개 유지) |
| 파티(영웅 여러 명) | 안 가져온다 — 코어는 주인공 한 명 구경. 대신 **제자**(v2.92)가 "옆에서 같이 크는 여러 명"의 역할을 화면 밖에서 한다 |
| 룬 트리(부/성장 두 갈래) | 이미 있음(수련 8 + 스킬 특성). 부 갈래(은자 획득·드랍률)를 **전각 산문·객당**에 더 실어도 된다 |
| 장터·거래·리셋 | 안 가져온다(방침: 광고·과금 없음, 프레스티지 없음) |
| 아이템 잠금·자동 채우기 | 자동 장착은 있음. 잠금은 합성이 낀 것도 먹는 우리 규칙에선 필요 없음 |

## 반면교사
- 봇·쌀먹으로 장터가 망가지고 안티치트 오탐으로 평가가 51%로 떨어졌다 — **경제를 외부에 열면 게임이 아니라 시장을 운영하게 된다.**
- 오프라인에 핵심 보상(상자)을 안 주면 "자리를 비우지 말라"는 신호가 된다 — 방치형의 약속과 반대.
