# 문파 인물 공격 이펙트 설계 (v2.95.4~)

사용자 확정 2026-09-17 "각 모션에 맞는 스킬 이펙트도 구상해 놔, 네가 직접 넣을 거".

주인공은 이미 동작마다 결이 다르다(`FXD.moveFx[P.atkKey]` → `heroImpactFx`, 30-combat 178줄).
**적에게는 그런 표가 없다** — 지금은 공격이 닿으면 `sfx('punch')` 하나뿐이라, 공격이 세 벌이어도
맞는 느낌이 다 같다. 여기에 같은 틀을 얹는다.

## 얹는 자리

- 데이터: `FOEFX`(00-data) — `'<몹키>.<공격키>' → 결 이름`. 없으면 몹의 기본 결, 그것도 없으면 무결(지금과 같다).
- 엔진: `foeImpactFx(f)` (30-combat) — `hurtHero()` 를 부르는 자리에서 같이 부른다.
  근접은 **주인공 몸 앞**, 원거리 탄은 **탄이 터지는 자리**. `heroImpactFx` 와 같은 `fxPush` 조각들(wave·rays·sparks·streak·slash·flash)을 쓴다.
- 결은 새로 만들지 않는다. `FXD` 에 이미 있는 것(impact·rise·qi·kick·cut·cutdown·pierce·spin·blunt·petal)에
  **색만 문파색으로** 바꿔 쓰고, 모자란 둘(`ripple`·`cloud`)만 더한다.

## 새로 만들 결 둘

- **`ripple`** — 바닥에 퍼지는 **납작한 타원 고리** 두 겹(반지름이 서로 다르게 자란다). 아미 장로 파문·청죽 장로 발구르기.
  `FXD.ripple = { r:14, r2:26, sq:0.34, w:2, life:0.42, c:… }`. `drawFx` 에 `ellipse` 로 그린다(**`createRadialGradient` 금지** — jsdom 이 터진다).
- **`cloud`** — 뭉게뭉게 퍼지는 **반투명 덩이 여럿**(각자 조금씩 다른 속도로 커지며 옅어진다). 당문 장로 독무.
  `FXD.cloud = { n:5, r:9, grow:26, life:0.7, a:0.5, c:… }`. 원 여러 개를 `globalAlpha` 로 겹친다.

## 이미 있는 이펙트 그림

초식·적 이펙트로 바로 쓸 수 있게 뽑아 둔 것들. `drawFoe` 와 별개로 `S.fx` 에 한 장짜리로 띄운다.

| 파일 | 내용 | 쓸 자리 |
|---|---|---|
| `assets/fx_lotus.png` | 금빛 연꽃 | 소림 장로 장풍 · 초식 후보 |
| `assets/fx_dust.png` | 크림빛 흙먼지 폭발 | 개방·화산 장로 내려찍기 |
| `assets/fx_qiray.png` | 청록 기운 줄기(161×24) | 개방 장로 찌르기 — **탄으로 쏜다** |

## 검증

`fxtest.js` 에 붙인다 — 몹 공격이 닿을 때 `FOEFX` 에 적힌 결의 `S.fx` 조각이 실제로 생기는지.
`FOEFX` 에 적어 놓고 코드가 그 결을 모르면 **조용히 아무것도 안 뜨므로**, 표에 있는 결 이름이 전부 구현돼 있는지도 같이 본다.
