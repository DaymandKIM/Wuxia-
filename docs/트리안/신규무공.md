# 신규무공 제안 — 7문파 트리 초안에서 나온 것

`src/65b-treedata.js` 통합 작업(v2.47) 중 각 문파 트리안(`docs/트리안/*.js`)이
제안한 `newArt`를 정리한다. 심법(패시브)은 바로 `ARTS.list`에 넣을 수 있는
형식으로, 액티브는 그림·연출 병목이라 보류하고 트리 노드는 임시로 패시브
%(`artPower:12`)로 대체해 두었다(`// TODO 액티브 <이름>` 주석 표시).

## 심법(passive) newArt — 6개, ARTS.list 편입 후보

`artDef(k)`가 그대로 읽을 수 있도록 기존 `chulwoo`·`honwon` 항목과 같은
형식으로 썼다. `TREEDATA`에서는 해당 노드의 `eff`를 `{art:'<k>'}`로만 남겨
뒀으니, 이 표를 `src/00-data.js`의 `ARTS.list`(`// ── 심법 (패시브 증폭) ──`
구간)에 그대로 추가하면 습득이 실제로 작동한다.

```js
// 소림 — 항마진경(s20)
{ k:'hangma',    n:'항마진경',   h:'降魔眞經',   type:'passive', school:'sorim',   need:21, cost:42000,
  d:'마를 항복시키는 경으로 몸이 금강처럼 굳는다', hp:0.18, dmg:0.12 },

// 화산 — 매향심결(h8) ※ 엔진 주의: 아래 참고
{ k:'maehyang',  n:'매향심결',   h:'梅香心訣',   type:'passive', school:'hwasan',  need:8,  cost:1000,
  d:'매화 향기가 스미듯 몸에 밴다', aspd:0.15, crit:0.08 },

// 아미 — 백련심공(a13)
{ k:'baekryeon', n:'백련심공',   h:'白蓮心功',   type:'passive', school:'ami',     need:20, cost:30000,
  d:'진흙 속에서도 물들지 않는 흰 연꽃 — 자비로운 기운이 몸을 감싼다', regen:0.25, hp:0.10 },

// 개방 — 취권결(g18)
{ k:'chwigwon',  n:'취권결',     h:'醉拳訣',     type:'passive', school:'gaebang', need:14, cost:4000,
  d:'취한 듯 흐트러진 몸놀림이 오히려 빈틈을 없앤다', dmg:0.12, spd:0.08 },

// 당문 — 만독불침공(d17)
{ k:'mandok',    n:'만독불침공', h:'萬毒不侵功', type:'passive', school:'dangmun', need:15, cost:8000,
  d:'온갖 독에 물들어 오히려 독이 힘이 된다', dmg:0.12, hp:0.12 },

// 마교 — 탈혼공(y14)
{ k:'talhon',    n:'탈혼공',     h:'奪魂功',     type:'passive', school:'magyo',   need:24, cost:90000,
  d:'상대의 기운을 빼앗아 자신의 것으로 돌린다 — 흡성 심법', dmg:0.15, regen:0.15 },
```

**엔진 주의 (매향심결만 해당)**: `artMul(kind)`는 `dmg`·`hp`·`regen`·`spd`
네 가지만 `heroDmg`·`heroHpMax`·`heroRegen`·`heroSpd`에서 실제로 곱해진다
(`00-data.js`). `heroAtkSpd`·`critCh`는 `artMul`을 부르지 않으므로, 매향심결의
`aspd:0.15`·`crit:0.08`은 **지금 그대로 넣으면 습득만 되고 전투엔 반영되지
않는다**. 채택하려면
```js
heroAtkSpd = ()=> (1+(statBonus('aspd')+tBonus('aspd'))/100) * artMul('aspd')
critCh     = ()=> (statBonus('crit')+tBonus('crit'))/100 + (artMul('crit')-1)
```
처럼 aspd·crit도 `artMul` 경로를 타도록 `30-combat.js`/`00-data.js`를 넓혀야
한다(사람 확인 후 반영). 나머지 5개(hangma·baekryeon·chwigwon·mandok·talhon)는
전부 dmg/hp/regen만 써서 지금 엔진 그대로 작동한다.

## 액티브(active) newArt — 3개, 보류

그림·연출(cast 스트립·탄·fxtest 케이스)이 새로 필요해 이번 통합에서는 채택하지
않았다. `TREEDATA`의 해당 노드는 `art`/`newArt`를 빼고 `{artPower:12}` 패시브로
임시 대체했다(`// TODO 액티브 <이름>` 주석). 원래 제안 스펙은 아래에 보관한다 —
그림이 준비되면 이 스펙으로 `ARTS.list`에 액티브를 추가하고 트리 노드의 `eff`를
`{art:k}`로 되돌리면 된다.

```js
// 소림 — 금강파산권(TREEDATA.sorim의 s19)
{ k:'geumgang',    n:'금강파산권', h:'金剛破山拳', type:'active', school:'sorim',  need:16, cost:16000,
  d:'금강처럼 굳은 주먹이 산을 무너뜨린다', cd:11, mul:4.5, range:90 }
// 연출 제안: 파공권 시전 스트립(HFX.cast.pagong) + 정권 교대 타격(katka/katkb) 재사용 — 신규 그림 없음.

// 무당 — 태극환장(TREEDATA.mudang의 m12)
{ k:'taegeukhwan', n:'태극환장',   h:'太極還掌',   type:'active', school:'mudang', need:18, cost:20000,
  d:'원을 그리듯 받아 흘려 후려친다', cd:11, mul:2.8, range:82, kb:true }
// 연출 제안: 건곤이형 태극 원반(gshield)을 무당 청색으로 톤만 바꿔 재사용 +
// 선풍퇴(whirl)의 회전 스텝·kb 넉백 판정 재사용 — 신규 그림 없음.

// 화산 — 표매권(TREEDATA.hwasan의 h14)
{ k:'pyomae',      n:'표매권',     h:'飄梅拳',     type:'active', school:'hwasan', need:17, cost:17000,
  d:'매화 흩날리듯 표홀하게 세 번 스쳐 친다', cd:7, mul:4.2, range:70, hits:3 }
// hits:3(다단 히트)은 기존 ARTS 스키마에 없는 신규 필드 — 채택 시 30-combat의
// 초식 판정에 다단 히트를 추가하거나, hits를 버리고 mul 하나(기존 pagong처럼
// 단일 판정)로 단순화해야 한다. 연출은 파공권 cast 스트립 재사용 + HFX.glow
// 화산 홍(#e89aad) 틴트로 제안.
```
