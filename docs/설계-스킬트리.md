# 문파 무공도 (스킬트리) — 설계 계약

사용자 확정(v2.44 시점):
- **문파 = 탭**, 탭마다 위(입문)→아래로 뻗는 **거미줄 노드망**. 문파당 **20~30노드**.
- 노드 개방 재화 = **경지 포인트만**(성이 오를 때마다 무공점 +1). 되돌리기 자유.
- **무공만 트리**(수련 8스탯은 지금 패널 그대로, 트리와 분리).
- 장무기형 = 여러 문파를 모은다. **문파 교차 키스톤**으로 조합.

## "다 만들 수 있나"의 답 — 노드 8:2 구성
- **패시브 잔가지(70~80%)**: `treeBonus(key)`에 합산되는 +% 한 줄. 새 코드·그림 없음.
- **무공 마디(문파당 3~6)**: 기존 ARTS의 초식(active)/심법(passive)을 습득시킴.
  `S.arts[k]=1`로 기존 자동시전·스킬창·연출을 그대로 탄다. **액티브 신규는 소수**만
  (그림·연출 비용) — 대부분은 기존 무공 재사용 + 패시브.
- **키스톤(문파당 1~2)**: 특수 변형/트레이드오프. 엔진이 개별 처리.

## 노드 데이터 형식 (한 노드)
```js
{ id:'b3', x:96, y:214, k:'major', need:['b1'],
  g:'竹', n:'청죽공', h:'靑竹功', c:2,
  eff:{ art:'chulwoo' },            // 효과 (아래 어휘 중 하나 이상)
  d:'심법 · 지닌 채 싸우면 …' }
```
- `id` 문파 내 유일. `x,y` SVG 좌표(폭 360 기준, 위 44 시작, 아래로). `need` 이어진
  앞 노드들(모두 익혀야 열림). `k` 종류. `g` 한자 한 글자(마디·키스톤만, 잔가지는 '').
  `n` 이름, `h` 한자 전체, `c` 무공점 비용, `d` 설명(HTML — `<span class="eff">`로 효과 강조).
- **좌표 규칙**: 폭 0~360, 가로 중앙 180. 한 줄에 2~3노드씩 지그재그로 내려가며
  거미줄처럼 교차 간선을 만든다. 세로 간격 ~70. 25노드면 y가 ~44에서 ~900까지.
- `k` 종류: `root`(입문, c:0) · `minor`(잔가지 %) · `major`(무공) · `keystone`(비전) · `cross`(문파 교차)

## 효과 어휘 (`eff`) — 이게 전부다. 새 키 만들지 말 것
패시브 %(잔가지·키스톤): 값은 정수 %. 잔가지 5~10, 강한 잔가지 12, 키스톤 20~40.
| 키 | 뜻 | 전투 반영 |
|---|---|---|
| `atk` | 공격력 +N% | heroDmg |
| `hp` | 체력 +N% | heroHpMax |
| `regen` | 회복 +N% | heroRegen |
| `spd` | 이동 +N% | heroSpd |
| `aspd` | 공격 속도 +N% | heroAtkSpd |
| `crit` | 치명 확률 +N% | critCh |
| `cdmg` | 치명 피해 +N% | critMul |
| `gold` | 은자 획득 +N% | killSilver |
| `artPower` | 초식 위력 +N% | 액티브 초식 피해 |
| `passiveAmp` | 심법 효과 +N% | artMul 증폭 |
| `cdr` | 초식 재사용 -N% | 초식 쿨다운 |
| `castSpd` | 시전 속도 +N% | 시전 재생 |

무공 마디: `{ art:'<ARTS.list의 k>' }` — 그 무공을 습득시킨다(경지 조건 대신 트리로).
  기존 무공 키: 초식 pagong·whirl·baekbo·hwalin·bungsan / 심법 samjae·chulwoo·yuwoon·honwon·taeheo.
  **신규 무공을 넣고 싶으면** eff에 `{ art:'<새 k>', newArt:{...ARTS 스펙} }`로 제안만 하고,
  액티브면 "연출 재사용/절차" 주석을 단다(그림 병목이라 최종 채택은 사람이).

키스톤 특수: `{ keystone:'<식별자>', ...설명필드 }` — 엔진이 개별 구현. 일단은 큰 패시브
  %(예: artPower:40) + 트레이드오프(예: 다른 계열 -10%)로 표현. 교차는 `cross:'<문파키>', crossNode:'<노드id>'`.

## 무공 작명 규칙 (docs/조사-무공작명.md 요약 — 반드시 지킬 것)
- 김용 고유 창작명·소림 72절기 실명 금지(소송). **문파명은 자유**(실존 지명·일반명사).
- 접미사: 초식 ~권/장/지/참/퇴/보, 심법 ~심법/공/결, 신공 ~신공. 수식부를 신조.
- 초식명 3~4자(외치기 좋게). 잔가지 소절은 ~결/~공/~보 등 짧게.
- 문파 색·기풍에 맞는 한자. 한자 전체(h)와 한글(n) 둘 다.

## 경지 포인트
- realmLv() = 누적 성 개수. **성 1당 무공점 +1.** skillPts = realmLv()×PTS_PER − 쓴 점.
- 되돌리기 자유(뒤 마디가 없을 때만). 저장에 익힌 노드 집합 + 무공점 보관.
