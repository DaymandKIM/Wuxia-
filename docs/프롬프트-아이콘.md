스킬창/타일에 잘 맞는다. 프롬프트에 "16-bit pixel"을 고집하지 말고 "round medallion,
painterly, crisp" 등으로 써도 됨. 스프라이트(인물·몹·소품)만 픽셀 그림체를 지킨다.
