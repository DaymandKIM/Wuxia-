# 무협 방치형

세로 화면 모바일 방치형 RPG. 자동 전투를 구경하는 게 코어다.
모듈로 나뉜 소스를 `build.py`가 **단일 HTML 하나**로 묶는다.
서버·번들러·프레임워크 없이 브라우저에서 바로 열린다.

```bash
npm i                  # jsdom (검증 도구용)
python3 build.py       # → dist/wuxia.html
open dist/wuxia.html
```

**작업 전에 `CLAUDE.md`를 먼저 읽어라.** 지켜야 할 규칙과 그동안 겪은
스프라이트 사고들이 정리돼 있다.

---

> **현재 v1.8** — 변경 이력은 `VERSION.md`.

## 지금 상태
**5구역 × 10단계 = 50단계.** 무기 없음. 맨손 정권 찌르기만.

| 구역 | 배율 | 배경 |
|---|---|---|
| 죽림 | ×1.00 | ○ |
| 폐촌 | ×1.90 | ○ |
| 동굴 | ×3.40 | ○ |
| 설산 | ×5.60 | ○ |
| 천산 | ×9.00 | ○ |

사막은 배경 시트가 없어 아직 넣지 않았다.

**지금은 테스트 모드다** (`00-data.js`의 `TEST = true`).
우하단 **사냥터** 버튼을 누르면 5구역 × 10단계 = 50개 버튼이 나오고
어디로든 바로 이동한다. `TEST = false`로 바꾸면 해금 조건이 걸린다.

## 구조
```
src/00-data.js     설계 숫자 전부 (여기만 보면 밸런스가 보인다)
src/10-engine.js   캔버스·이미지 로딩·잡다
src/15-audio.js    합성음 (슉·타격·처치·쓰러짐)
src/20-state.js    S(게임) · P(주인공)
src/30-combat.js   공격·피해·쓰러짐
src/40-step.js     매 프레임 갱신
src/50-render.js   그리기
src/60-ui.js       HUD·토스트
src/70-main.js     시작·루프

assets/*.png       스프라이트 (파일명 = 키)
build.py           → dist/wuxia.html (WUXIA_OUT으로 경로 변경)
sim.js             30분 진행 시뮬레이션
test.js            브라우저 환경 실행 검증
```

## 원칙
1. **숫자는 `00-data.js`에만.** 코드에 상수를 박지 않는다.
2. **이미지는 기다리지 않는다.** `draw()`가 준비 안 된 것을 건너뛴다.
3. **스프라이트는 한 규격.** 주인공 56×83 고정. 동작마다 다르면 위치가 튄다.
4. **바꾸면 `sim.js`를 돌린다.** 감으로 밸런스를 만지지 않는다.

## 검증
```
python build.py     # 빌드
node sim.js         # 30분 진행 (단계·쓰러짐 확인)
node test.js        # 실제 실행 (오류·그리기 확인)
```

## 현재 밸런스 (sim.js) — **임시**
성장 축이 무공·장비뿐 아니라 여럿 들어오면 다시 잡는다.
지금은 진행이 막히지 않는지만 확인한 값이다.

## 단계 진입 연출
배경 3장(`assets/bg1~3.png`)이 2.4초 동안 차례로 바뀐다.
원경 산 → 안개 숲 → 깊은 대숲. **원본 비율 그대로 가로를 화면에 맞추고 위아래는 검정.**
확대나 흐름 없이 화면만 넘어간다. 길이는 `00-data.js`의 `INTRO.dur`.

## 주먹 이펙트
원본 그림에 손 끝이 잘려 있다. `00-data.js`의 `FIST` 배열에
공격 프레임별 주먹 위치를 적어두고, 그 자리에 작은 원을 얹어 마무리한다.
주인공과 같은 변환 안에서 그리므로 좌우가 자동으로 맞는다.

## 운기조식
쓰러지면 3초간 명상 자세. `QI` 상수로 기운 방울을 조절한다.
바닥에서 피어올라 몸을 타고 흩어지고, 방울마다 시작 시각이 달라 끊이지 않는다.

## 테스트 버튼
`TEST = true`일 때만 화면 좌하단에 **운기조식** 버튼이 나온다.
누르면 즉시 쓰러져 3초간 명상 자세를 재생하고 복귀한다.
`TEST = false`면 버튼이 사라진다.

## 단계 제패
처치 목표를 채우면 바로 넘어가지 않고 **기운을 터뜨려 주변을 쓸어낸다**.
0.6초 모으고 1.15초 퍼진 뒤 0.35초 여운.
- 모을 때: 리본 3줄이 궤도를 따라 감겨 든다
- 터질 때: **곡면 꺼풀 4겹이 이어져 훅 퍼진다** — 안팎 두 곡선을 이어 띠 면을 만들고
  (`curveLoop`), 둘레 46점을 물결치게 흔든다. 반경 380px까지 나가며 옅어진다.
- **파동 앞머리가 닿는 순간** 적이 차례로 쓰러진다 (가까운 쪽부터)

`SWEEP` 상수로 조절한다.

## 보스
등장할 때 **문이 솟고 청록 기운이 세 겹 회오리로 감아 든다** (3.4초).
알갱이 48개가 꼬리를 남기며 모이고, 다 모이면 터지면서 **마왕이 문에서 걸어 나온다**.
보스 단계에는 잡몹이 나오지 않는다.
등장 후 **구역별 문구**가 뜬다 (`BOSSCRY`) — 죽림이면 "죽림의 주인이 깨어난다".
체력바는 보스 머리 위에 붙는다. `SUMMON` 상수로 조절한다.
보스는 **그림자 대신 기운에 감싸인다** — `fx_aura` 이미지를 3겹으로 연하게 겹친다
(`drawAura`, `AURA` 상수). 투명도 0.30에서 시작해 층마다 옅어진다. 문도 같은 함수를 쓴다.

## 이펙트 원칙
스프라이트를 겹치지 않고 **점 → 선 → 면**으로 그린다.
등장 회오리와 클리어 파동 모두 궤적의 점을 이어 리본 면으로 만든다.
알갱이를 흩뿌리지 않으므로 따로 놀지 않고 하나의 흐름으로 보인다.
층마다 다른 속도로 넘실거리고 좌우로 살랑인다.
등장 연출이 끝날 때까지 전투가 시작되지 않는다.

`ZONEBOSS`에 구역별 보스 종류를 적는다. 없으면 그 구역 대표 잡몹을 1.55배로 키워 쓴다.
전용 스프라이트가 있으면 원래 크기 그대로 나온다.

| 구역 | 보스 | 전용 스프라이트 |
|---|---|---|
| 죽림 | 대나무 마왕 | ○ (92×111, 23프레임 · 주인공의 2.2배) |
| 나머지 | — | 강도 확대 |

구역마다 **11단계가 보스 스테이지**다. 10단계를 깨야 들어간다.
보스를 잡아야 다음 구역으로 넘어간다 (일반 단계처럼 처치 수로는 못 넘어간다).

| 항목 | 값 |
|---|---|
| 체력 | 10단계 적의 62배 |
| 피해 | 10단계 적의 2.4배 |
| 속도 | 0.82배 (느리다) |
| 크기 | 전용 스프라이트는 원본 크기, 없으면 1.55배 |
| 호위 | 3마리까지 |

23프레임을 전부 쓴다.
- **일반 공격** — 낫을 들어올려 땅을 내리찍는다 (swing 5프레임)
- **스킬** — 포효로 기운을 모아 터뜨린다 (roar 4 + burst 5 = 9프레임)

**스킬**을 5.5초마다 쓴다 — 1.35초 시전 후 반경 132px에 일반 공격의 2.6배 피해.
보라빛 고리가 땅을 훑고 화면이 흔들린다.

넉백이 안 통하고 붉은 기운을 두른다. 스프라이트에 어두운 외곽선을 둘러 바닥과 구분된다.
보스전에서는 카메라가 보스 쪽으로 당겨져 화면 밖으로 잘리지 않는다. 체력바는 화면 상단에 크게 나온다.
사냥터 패널의 붉은 **보스** 버튼으로 바로 갈 수 있다.

## 적
공격 판정은 **발 위치**에서 재고 세로를 1.55배 넓힌다 (`HERO.atkFlat`).
탑다운 시점이라 그냥 원으로 재면 위아래 적이 멀게 느껴진다.

`FOES` 표에 종류별 규격·동작·능력치를 적고, `ZONEFOE`로 구역별 등장 목록을 정한다.

| 종류 | 크기 | 체력 | 피해 | 속도 |
|---|---|---|---|---|
| 대나무 강도 | 56×51 | ×1.00 | ×1.00 | ×1.00 |
| 대나무 유령불 | 32×37 | ×0.62 | ×0.78 | ×1.22 |
| 그림자 표범 | 82×46 | ×0.78 | ×1.15 | ×1.45 |
| 대나무 주술사 | 67×56 | ×0.55 | ×0.85 | ×0.72 |

강도는 도끼를 3단으로 내려친다. 유령불은 약하지만 빠르고, 떠다니는 느낌으로 대기·이동이 이어진다.
표범은 가장 빠르고 사납다 — 도약해서 할퀴고 착지한다.
주술사는 **원거리**다. 사거리 108px에서 멈춰 초록 기운을 쏘고, 너무 가까우면 물러난다.
탄은 주먹 이펙트와 같은 이중 구조에 색만 초록(`drawShots`).
7.5초마다 **큰 마법 구체**를 날린다 — 느리지만 피해 2.2배에 반경 26px.
`shaman_m2`는 인물이 아니라 **구체 그림**이므로 캐릭터 동작이 아니라 탄으로 쓴다.

추출 스크립트는 종류마다 하나씩 둔다 (`bandit.py`, `wisp.py`).
마젠타 배경은 크로마키로, 어두운 배경은 밝기·색조로 자른다.
